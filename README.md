# Linkposter

![License](https://img.shields.io/badge/license-MIT-blue.svg) [![Latest Stable Version](https://img.shields.io/packagist/v/redundans/linkposter.svg)](https://packagist.org/packages/redundans/linkposter) [![Total Downloads](https://img.shields.io/packagist/dt/redundans/linkposter.svg)](https://packagist.org/packages/redundans/linkposter)

A [Flarum](https://flarum.org) extension. Accept URLs instead of discussion titles for a hacker news type of posts.

## Installation

Install with composer:

```sh
composer require redundans/linkposter:"*"
```

## Updating

```sh
composer update redundans/linkposter:"*"
php flarum migrate
php flarum cache:clear
```
